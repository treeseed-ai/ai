# TreeAI 0.11.0

TreeAI 0.11.0 separates the independently runnable inference, training, and lab products into immutable TreeSeed component releases and publishes the generic `@treeseed/treeai` SDK contract.

The release contains authoritative OpenAPI 3.1.1 documents, a digest-bound operation inventory, generated TypeScript operation types, exact image inventories, and Deployment-owned runtime contracts. TreeSeed host lifecycle and integrated Platform composition are adopted downstream through `@treeseed/sdk` and Deployment; TreeAI does not publish or own a competing host APT lifecycle.

Existing 0.10 training evidence remains valid because this release changes the integration and delivery boundary rather than the model, dataset, Marker, Axolotl, CUDA, or adapter-training fingerprints. Deployment migration and one final release-candidate training-loop gate remain required before stable ecosystem promotion.
