# TreeAI 0.8.0

TreeAI 0.8.0 makes Hermes a private, authenticated agent backend behind the
same experience proxy used by Open WebUI. The browser model list now includes
`local-model` for direct inference and `hermes-agent` for bounded agent runs.

Hermes runs as separate gateway and password-protected dashboard services on
an internal lab network. Its workspace persists, its API concurrency is capped
at two, and its available tools exclude cron, delegation, MCP, Docker, host
control, and project mounts. Web work uses a credential-free TreeAI worker that
rejects internal addresses and records retrieval provenance.

The lab begins immutable v2 inference captures, agent trajectories, action
sequences, and artifact observations. Contracts reserve independent eligibility
and lineage for future continual pretraining, corrective SFT, and KTO. Those
training pipelines remain disabled until separately qualified.

Operational additions include `treeai lab open hermes`, Hermes status/tool/
session commands, hash-only dashboard password storage, root-only transactional
password rotation, and `treeai lab verify --deep`.

Only `lab-controller`, `lab-experience-proxy`, `hermes-agent`, and the new
`lab-web-tool-proxy` image change. All inference, training, vLLM, evaluator,
Marker, Axolotl, artifact, migration, and Open WebUI digests are reused.
