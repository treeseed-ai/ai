# TreeAI 0.9.0

TreeAI 0.9.0 closes the first knowledge-learning loop. Open WebUI Knowledge Bases map to immutable TreeAI libraries, documents are normalized through direct text processing or Marker, and explicit smoke or standard cycles build Axolotl completion-pretraining QLoRA adapters.

Key changes:

- A private library bridge preserves ordinary Open WebUI upload and RAG behavior while streaming accepted library files to the authenticated training API.
- Content-addressed source objects, document revisions, hierarchy, snapshots, datasets, training runs, adapter lineage, and processing diagnostics are durable and auditable.
- PDF, DOCX, PPTX, and HTML use balanced Marker processing. Supported UTF-8 text and source formats use deterministic direct normalization. Unsafe, unsupported, encrypted, or secret-bearing inputs fail closed.
- Smoke runs qualify the GPU pipeline with at most 16 optimizer steps and can never promote.
- Standard runs reserve whole documents for held-out completion likelihood and update only their `library/<slug>` alias when strict behavior and improvement gates pass.
- `local-model`, Hermes, unrelated library aliases, and existing Open WebUI data remain independent.

Rollback restores the prior package and image generation. Additive library database tables and immutable objects remain intact and inactive for audit or later recovery.
