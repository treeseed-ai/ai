# TreeAI 0.7.1

TreeAI 0.7.1 repairs the privileged manager socket used by fixed local lifecycle
operations. A client may half-close its request stream without closing the
supervisor's response stream, and expected operation errors return complete JSON
instead of terminating the supervisor.

The repair adds no new privileged operation. The existing supervisor allowlist,
root-only socket permissions, request size limit, and fixed operation parameters
remain unchanged. Client disconnects are contained and recorded without removing
the control socket.

This hotfix was qualified through the continuous development channel before
stable publication. Product data, model processes, and unchanged container image
identities are unaffected.
