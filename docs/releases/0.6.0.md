# TreeSeed AI 0.6.0

TreeSeed AI 0.6.0 introduces the single-download `treeseed-ai` bootstrap and transfers factory lifecycle ownership to `treeseed-ai-manager`.

The bootstrap installs the signed repository and asynchronously converges the configured product set. Stable updates are staged daily and applied in the configured maintenance window. The separately signed development channel polls every 60 seconds and applies compatible generations only after validation and safe drain.

This release is breaking. Existing 0.5 local factories are migrated with their credentials, CA, data volumes, object stores, and persisted GPU mode preserved. Local-source deployments migrate to `imageSource=local-build` with stable updates paused until explicitly selected.

The downloadable configured package can contain temporary TreeAI-owned bootstrap credentials. They are replaced before public APIs bind; delete the downloaded installer after successful handoff. External service credentials remain secret-provider references and are never embedded.
