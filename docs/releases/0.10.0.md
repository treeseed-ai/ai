# TreeAI 0.10.0

TreeAI 0.10.0 turns promoted library adapters into Hermes-backed agent profiles and adds reproducible machine qualification, bounded context management, multimodal document evidence, disjoint language/vision adapter composition, and public qualification-corpus acquisition.

The automatic baseline is keyed to the GPU, driver, runtime, model, worker images, and relevant configuration. It retains the known-good profile on failure. The explicit balanced campaign is bounded to four hours and 24 fixed trials, records empirical capability and concurrency evidence, stops early when trials cease improving, and activates only a strictly better passing profile.

Open WebUI model discovery now includes `agent/auto` and enabled `agent/<slug>` profiles. Agent selections remain pinned within task segments; explicit handoffs create immutable routing decisions. Context compaction keeps tool call/result spans atomic and stores oversized tool results as content-addressed artifacts.

Marker document bundles preserve Markdown, structured blocks, page mappings, captions, extracted images, and checksums. Training can produce language and vision QLoRA adapters and compose them only through an exact tensor union with disjoint target modules. Multimodal serving remains disabled until the host profile passes its explicit gate.

Qualification inputs are acquired rather than committed. The release catalog pins a cross-sector SEC issuer allowlist and NASA technical-report URLs and checksums. Set `SEC_USER_AGENT` to an organization and contact email before running `treeai lab corpus acquire --qualification`.

Corrective SFT and KTO execution remain future work. Qualification corpora and their adapters are non-production evidence used to establish machine limits and end-to-end behavior.
