# TreeSeed AI 0.6.2

TreeSeed AI 0.6.2 hardens the managed-platform handoff and leaves platform
status concise after migration. The manager now reports only stable product,
service, state, health, and immutable image identity fields instead of exposing
raw Docker Compose inspection records.

Upgrades repair the manager's configuration and SQLite permissions, while new
installations create a traversable but non-listable `/etc/treeseed-ai` root.
Configuration adoption, channel changes, and recovery preserve those
permissions. The manager API therefore remains available without granting it
root or Docker access.

The explicit 0.4 takeover now stops the legacy TLS gateway before manager-owned
packages are installed, preventing host-port collisions. If failure occurs
before package installation, rollback restores both the old coordinator and
gateway. Durable volumes are never removed.

Large image acquisition emits a concise role-prefixed heartbeat every 15
seconds, making long vLLM or worker pulls visibly active without dumping Docker
progress internals. Unchanged image identities continue to be reused by the
selective release workflow.

Upgrade an existing managed installation with:

```bash
sudo treeai update check
sudo treeai update plan
sudo treeai update apply
treeai platform status
```
