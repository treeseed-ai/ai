# TreeSeed AI 0.5.0

This breaking release introduces the required `treeseed-ai-cli` package and
the unified `treeai` command, adds the inert `treeseed-ai-factory`
meta-package, and coordinates published Docker images with digest-pinned
Debian installation metadata. Legacy public command names are removed.

Upgrade 0.4.0 factory ownership cleanly before installing 0.5.0, then use
`treeai doctor`, `treeai factory configure`, `treeai factory pull`, and
`treeai factory start`.
