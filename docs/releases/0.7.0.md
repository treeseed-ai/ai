# TreeAI 0.7.0

TreeAI 0.7.0 adds an explicit local single-user Open WebUI development mode.
The browser UI binds only to `127.0.0.1:443`, uses the TreeAI local CA, and
reaches inference exclusively through the experience-capturing proxy.

## Upgrade

After the manager installs the 0.7.0 packages, stage and activate the local UI:

```bash
sudo treeai lab configure --local-single-user
sudo treeai lab reset-webui --confirm
treeai lab verify
treeai lab open webui
```

The reset is explicit because Open WebUI supports disabling authentication only
with a fresh user database. TreeAI archives the old `open-webui-data` volume,
records its checksum, and restores it automatically if activation fails.

## Security boundary

Open WebUI receives a non-secret proxy identity, not the inference service key.
The experience proxy injects the scoped upstream credential, preserves streaming,
and attributes captured conversations to `open-webui`. Raw vLLM remains private.

The CA is available at `/etc/ssl/certs/treeseed-ai-ca.pem`. Browser-specific CA
import may still be required, particularly for sandboxed browser packages.
