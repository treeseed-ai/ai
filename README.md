# TreeSeed AI

This repository is the initialization scaffold for the future TreeSeed local AI appliance package.

Planned responsibilities include vLLM inference, Axolotl training, local appliance supervision, hardware diagnostics, and Debian packaging. None of those runtime capabilities is implemented or claimed yet.

TreeSeed API remains the governance and control-plane scheduler. This appliance will not directly mutate project Git repositories: content uses assignment-scoped TreeDX operations, while provider work uses capacity assignments, leases, usage, and settlement.

## Current commands

`npm run build`, `npm test`, and `npm run verify` validate this metadata scaffold.
